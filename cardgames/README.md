# 星域牌类游戏

服务端权威的多人实时牌类游戏，供星域小游戏大厅调用。

## 玩法

| 游戏 | 玩法 | 对手 | 说明 |
| --- | --- | --- | --- |
| 斗地主 | 标准斗地主 | 3 位平台用户 | 叫地主 → 出牌 → 平台钱包结算，含炸弹翻倍 |
| 麻将 | 推倒胡 | 4 位平台用户 | 可碰、可明杠/暗杠，不吃；胡型为标准型与七小对 |
| 红中麻将 | 红中赖子 | 4 位平台用户 | 红中可替代将牌、刻子或顺子，独立规则与匹配池 |
| 跑得快 | 三人 48 张 | 3 位平台用户 | 黑桃 3 首出，服务端提示可出牌型 |
| 炸金花 | 三张比牌 | 3 位平台用户 | 看牌、过牌、下注、跟注、弃牌、比牌 |

所有游戏均默认进入各自的 1000 桌匹配池，手机端强制横屏提示。每局统一从平台钱包扣 100 星币入桌，
结束后本金与输赢通过 core 幂等结算接口返还。游戏进程不直连用户表，也不保存独立余额。

## 牌型与番型

斗地主支持：单张、对子、三张、三带一、三带二、顺子（≥5 连）、连对（≥3 连对）、
飞机、飞机带翅膀、四带二、炸弹、王炸。压制规则：同型同长比大小，炸弹压普通牌，王炸最大；
资金桌倍数封顶 32 倍，确保最大责任不超过已收取的入桌金。

麻将番型：平胡 1 番，七小对 +3，碰碰胡 +2，清一色 +3，每个杠 +1，自摸 +1；
红中规则在使用赖子成牌时额外显示“红中赖子”并加番。

炸金花牌型：豹子 > 同花顺 > 金花 > 顺子 > 对子 > 单张，A23 按最小顺子计算。

跑得快复用完整组合判定，支持单张、对子、三张、三带、顺子、连对、飞机、四带二与炸弹。

## 服务端权威

发牌、洗牌（crypto 强随机）、牌型判定、真人操作校验、胡牌判定、番数计算全部在服务端。
客户端只提交动作（出哪几张牌 / 打哪张牌 / 碰杠胡），
服务端校验是否为手牌子集、牌型是否合法、能否压过上家，并且**视图不包含他人手牌与牌墙内容**。

## 本地运行

```bash
npm install
npm start          # 默认 3000 端口
npm test           # 47 项规则、完整自动对局、钱包与多人联机测试
```

正式环境需从平台大厅进入；启动 URL 会携带短期签名、用户身份和自动匹配桌号。

## 子路径挂载

设置 `BASE_PATH` 即可挂到反代子路径，静态资源与 API 会同时挂根路径和子路径：

```bash
BASE_PATH=/minigame/cards npm start
```

## 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/ddz/new` | 开局，返回 gameId 与视图 |
| POST | `/api/ddz/bid` | `{gameId, call}` 叫/不叫地主 |
| POST | `/api/ddz/play` | `{gameId, cards:[]}` 出牌 |
| POST | `/api/ddz/pass` | `{gameId}` 不要 |
| POST | `/api/mahjong/new` | 开局 |
| POST | `/api/mahjong/discard` | `{gameId, tile}` 打牌 |
| POST | `/api/mahjong/peng` \| `/gang` \| `/concealed-gang` \| `/win` \| `/skip` | 碰/杠/暗杠/胡/过 |
| GET | `/health` | 健康检查 |

旧 HTTP 单机接口仅保留给规则回归测试；正式对战使用 Socket.IO 的
`match:join / game:action / match:ready`，每位用户只能看到自己的手牌。
