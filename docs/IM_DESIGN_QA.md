# IM 前端设计与验收准则

## 强制居中

- `button`、小型功能按钮、图标按钮、状态标签、徽标和计数标签必须同时使用水平与垂直居中。
- 实现基线为 `display: flex` 或 `inline-flex`，并同时设置 `align-items: center`、`justify-content: center` 和 `text-align: center`。
- 同类控件必须使用统一高度、圆角、内边距与点击热区，不允许文字只靠行高、空格或局部偏移“看起来居中”。
- 列表行、表单设置行等承载多列信息的复合容器可以使用两端布局，但其中的功能按钮、图标容器和标签仍必须独立强制居中。

## IM 页面验收

- 消息中心覆盖会话列表、未读数、群聊补位、系统通知、搜索、隐藏会话和实时连接状态。
- 单聊与群聊覆盖文字、图片、语音、视频、文件、历史分页、已读、撤回、本地删除和实时收取。
- 单聊覆盖用户屏蔽与解除屏蔽；群聊覆盖全员禁言下的输入限制。
- 群管理覆盖资料、公告、入群策略、成员邀请、角色、成员禁言、移除、群主转让、退出和解散。
- 375px、390px 与 430px 手机宽度下不得出现横向滚动；底部输入区和固定按钮必须适配安全区。

## 本地数据与帐号隔离

- App 端会话、消息、群资料、群成员、入群申请、黑名单和本地删除标记统一写入 SQLite；H5/小程序仅使用按帐号分区的兼容缓存。
- SQLite 每条记录必须包含 `owner_uid`，所有查询、更新与删除都必须同时限定当前帐号，禁止跨帐号读取或覆盖。
- 每次异步读写开始时固定本次操作的帐号 ID，等待数据库或网络结果期间即使切号，也不得把旧帐号数据写入新帐号分区。
- 切换帐号后必须关闭旧 WebSocket、清理旧会话映射和事件订阅；旧帐号的网络回包与连接事件必须直接丢弃。
- 退出帐号不删除其独立缓存；再次登录同一帐号可恢复自己的本地聊天数据，但不能看到其他帐号的任何数据。
