# 深海猎手（四座实时街机捕鱼）

一个可直接在浏览器运行的传统四座捕鱼桌。最多 4 位玩家使用同一房间号进入同一张共享海域，从上排两座、下排两座炮位同时瞄准、开炮和捕鱼。

## 这版的捕鱼规则

这不是“把鱼血量打到 0 就必杀”的射击游戏。服务端按传统倍率捕鱼方式分两步结算：

1. 炮弹与鱼的有效碰撞只负责触发一次捕获尝试和渔网特效。
2. 服务端使用安全随机数，按 `捕获概率 = 目标 RTP ÷ 鱼倍率` 决定捕获或逃脱。

默认目标 RTP 为 `0.72`。例如 2 倍鱼单次有效命中的捕获概率为 36%，20 倍鱼为 3.6%，80 倍鱼为 0.9%。成功奖励为 `当前炮值 × 鱼倍率`；失败时鱼继续游动，不存在隐藏血条或累计伤害。炮值档位为 `1 / 2 / 5 / 10 / 20 / 50`。

随机数、倍率、炮值、积分和最终结果全部由服务端决定。客户端提交的 `captured`、`payout` 或伪造炮值不会参与结算。

## 已实现

- 一张共享深海战场，上排两座、下排两座完整炮架与独立座位 HUD
- 单房间最多 4 人，所有玩家看到同一鱼群、炮弹和概率结果
- 明亮热带街机海域、体积光、气泡粒子及 10 种原创鱼类
- 金枪鱼、狮子鱼、河豚、石斑、海龟、蝠鲼、锤头鲨、章鱼、虎鲸和鮟鱇
- 服务端鱼群编队，同组鱼保持一致的速度、波形和队形
- 服务器权威的移动、碰撞、概率捕获、倍率奖励和开炮频率
- 炮档对应 6 套炮体配色与尺寸，命中渔网随炮值扩大
- 捕获爆金币、倍率文字和金币回收至获奖玩家炮台
- 20 Hz 房间模拟、10 Hz 快照、浏览器 60 FPS 插值渲染
- 开炮命令幂等、断线重连、短时席位恢复、多房间隔离和空房回收
- 桌面浏览器和手机横屏适配；手机竖屏打开时自动旋转为横向画布，鼠标与触摸坐标同步校正
- Docker Compose 一键启动和健康检查

游戏金额统一来自用户的平台钱包。进入捕鱼后由平台自动分配 `1..1000` 号桌；
每次开炮先经 core 钱包幂等扣款，捕获奖励再由 core 原路入账。浏览器与捕鱼进程都不能直接修改用户余额。

## 本地运行

需要 Node.js 20 或更高版本。

```bash
cd game
npm install
npm start
```

浏览器打开 `http://127.0.0.1:3000`。

验证多人时，让不同平台账号通过大厅进入同一张自动匹配桌。局域网其他设备可把 `127.0.0.1` 换成运行机器的局域网 IP。

## Docker 运行

在项目根目录运行：

```bash
docker compose up -d --build fishing-game
```

游戏入口为 `http://127.0.0.1:18082`，健康检查为 `http://127.0.0.1:18082/health`。

概率参数可通过 `TARGET_RTP` 环境变量调整，默认 `0.72`，有效范围会在服务端限制到 `0–1`。`MAX_ROOMS` 默认 1000。

## 多人同步边界

客户端只发送平台启动凭证、瞄准角度、炮值和开炮命令。客户端不能提交捕获结果、概率、倍率、奖励或余额。桌内模拟状态保存在单个游戏进程内，资金流水和最终余额持久化在平台数据库；水平扩容时必须为同一桌设置唯一权威进程和跨节点消息层。

Socket 服务默认只接受同源网页。若前端与游戏服务需要部署到不同域名，可在创建服务时显式传入允许的 `corsOrigin`。
