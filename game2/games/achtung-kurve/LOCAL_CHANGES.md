# Local collection changes

This copy is based on upstream tag `v1.5.1` at commit
`02702ad86319c22e28ab5cc2038ba39a4ba722a9`.

For private local play, this collection build changes the following behavior:

- Matomo/Piwik tracking methods are disabled.
- The remote Matomo opt-out iframe is removed.
- The cookie-consent prompt no longer blocks the game on first launch.
- The privacy dialog now describes the behavior of this local build.

The upstream author, repository, version, credits, source code, and GPL-3.0
license notice remain included. The generated files under `dist/` were rebuilt
from the modified source.
