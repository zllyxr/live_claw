## `game-center-title-v1.webp`

用途：游戏中心首页左上品牌标题。

最终生成要求：

```text
生成一条适用于手机游戏中心顶部的紧凑横向品牌字标。只保留一次中文标题“星域游戏中心”和一行小字“多人对战 · 资金结算 · 公平透明”。银白金属字面、克制的暖金描边、单条青蓝至紫色星轨；不使用独立重复徽标、面板、场景或多余文字。字体笔画需在约 300 CSS 像素宽时仍清晰。使用完全均匀的 #00ff00 色键背景，主体内不得使用绿色。
```

## `multiplayer-hall-title-v1.webp`

用途：游戏中心“多人游戏大厅”栏目标题。

最终生成要求：

```text
生成一条紧凑横向栏目字标。中文标题必须为“多人游戏大厅”，英文副标题必须为“LIVE GAME ARENA”，不得出现其他文字。延续银白字面、暖金描边与青蓝紫色轨道光，并加入少量橙金竞技光与主品牌形成区分。不要控制器、独立徽标、卡片或矩形面板。使用完全均匀的 #00ff00 色键背景，主体内不得使用绿色。
```

## 切图与交付

- 使用边缘自动取色色键、软蒙版和绿色溢色清理生成透明图。
- 按可见像素边界裁切并缩放至 1200 像素宽。
- 使用 WebP（有损质量 88、无损 Alpha）交付，兼顾手机清晰度和加载体积。
